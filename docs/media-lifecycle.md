# Хранение фотографий и документов

Актуальное поведение приложения:

- Архивирование скрывает файл, но сохраняет сам файл и запись `MediaAsset`.
  Автоматического удаления по сроку хранения сейчас нет.
- Отклонение модератором также не удаляет файл физически.
- При удалении `MediaAsset` через административные или программные операции
  физическая очистка выполняется только после успешного завершения всей
  транзакции базы данных. Это относится и к удалению профиля вместе с его медиа.
- При отмене транзакции или вложенного шага файл остаётся на месте вместе
  с восстановленной записью. Привязки источников и разрешения доступа также
  сохраняются благодаря откату базы данных.
- Успешное удаление документа не удаляет описание `Source`: очищается только
  ссылка на файл. Связь источника с биографией/событием остаётся, если сама
  биография или событие не удалены.

## Границы гарантии

База данных и файловое хранилище не образуют общую транзакцию. Если хранилище
недоступно после фиксации удаления, запись уже удалена, а файл может остаться.
Ошибка регистрируется в журнале приложения с ID медиа; очистка остальных файлов
продолжается. Остановка процесса между фиксацией базы и очисткой также может
оставить файл без записи. Постоянной очереди повторной очистки пока нет.

Оставшиеся файлы нельзя удалять массово без сверки с базой и резервной копией.
Автоматическая очистка таких файлов и сроки хранения требуют отдельного решения.
Этот механизм не заменяет резервное копирование базы и закрытого хранилища.

Для сверки базы и файлов есть безопасный отчёт без операции удаления:

```sh
docker compose exec -T web python manage.py media_storage_report --json
```

Он показывает отсутствующие зарегистрированные файлы, файлы без записи в базе,
символические ссылки и некорректные пути. Автоматическое удаление найденных
объектов намеренно не выполняется.

## Проверка

`heritage.test_media_cleanup` проверяет реальные фиксации и откаты на отдельной
тестовой базе. Файлы этих тестов находятся исключительно в памяти. Покрыты
обычное, массовое и каскадное удаление, вложенные транзакции, отсутствующий файл
и ошибка хранилища. Тесты не удаляют реальные семейные документы.
